# Archived World Movement research workspace

This directory preserves the small tracked description and reference manifest
from the World Movement Lab.

The high-volume processing areas now live under the ignored
`artifacts/research/world-movement/` workspace:

- `source/` — downloaded vendor archives and extracted source libraries;
- `generated-candidates/` — image-generation outputs and processing previews;
- `conditioning/`, `keypose-authority/`, and `silhouettes/` — intermediate
  pose guides, masks, cards, split frames, and review previews.

The active third-party motion package, exact source, license, and integrity
manifest live together under
`apps/launcher/static/assets/motion/quaternius-standard-v1/`.
