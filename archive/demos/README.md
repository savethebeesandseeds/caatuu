# Archived Caatuu demos

This directory preserves retired development experiments. It is not mounted or
served by the active Caatuu runtime and is not an asset authority.

## Available project

- `world-movement/` - character locomotion, pose-authority, sprite-generation,
  and browser-animation laboratory.

Only reviewed experiment code and small historical metadata are kept in Git.
Raw research inputs and generated candidates live in the ignored
`artifacts/research/world-movement/` workspace.

The Quaternius motion input formerly owned by this experiment was promoted to
`apps/launcher/static/assets/motion/quaternius-standard-v1/`; the archive does
not keep a second copy.
