# Word World content

Edit [content.json](content.json). This is the complete, authoritative sentence
catalog for this course, using the same format as the other courses.

The shared builder generates the runtime files and publication views. Any
`starter-v1.realizations.json` beside this file is a generated compatibility
view; do not edit it. Historical Czech batches and review receipts are evidence,
not inputs to normal builds.

See the [catalog guide](../../../../../docs/GAME_CONTENT_CATALOGS.md#word-world-one-editable-json-per-course)
for the fields, build commands and validation workflow. Content additions do
not require changes to the game interface or mechanics.
