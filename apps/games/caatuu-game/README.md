# Macaw adventure artwork

Status: **paused concept**. The retained work here is the
[character workshop](character-workshop/README.md), its
[animation workflow](docs/CHARACTER_ANIMATION_WORKFLOW.md), and the tools needed
to maintain it. The current learning app does not load this concept.

Start at the [resume guide](../lab/RESUME.md). Review the animations at
<http://127.0.0.1:8765/games/lab/motion> and movement at
<http://127.0.0.1:8765/games/lab/scenary>, through the existing local service.

The old Godot project, humanoid experiment, rigid parts costume and export
pipeline are preserved in the
[legacy archive](../../../archive/demos/caatuu-game-godot-v1/README.md).
This folder is no longer an executable Godot project or an active game-catalog
entry. Its historical name remains so selected asset and provenance paths stay
stable. Shared scenery, Quaternius references and Animated Fabric stay at their
existing canonical locations.

Retained tooling covers motion normalization, workshop snapshots and the shared
scenery atlas generator. Use the repository's documented containers for image
processing; see the animation workflow before changing selected frames.
