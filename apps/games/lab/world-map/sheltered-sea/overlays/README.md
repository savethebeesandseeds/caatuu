# Foreground overlays

No foreground images have been generated or approved yet. Use transparent PNGs
for canopy, roof or other scenery pieces the character should pass behind.

Record each overlay's section, position/anchor in master coordinates, scale,
source scenery version and review status in [the world manifest](../manifest.json).
Keep NPCs and interactive object states independently placeable as the runtime
is designed; do not bake them into the ground image.

Follow the [world map workflow](../../README.md).
