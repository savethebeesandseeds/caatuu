    Small scripts

    Read a dictionary item

    město town, city N n>město
    Jdu do města. do+G: města
    1. Top left: Czech word to recognize or say.
    2. Top middle: red translation, so you can scan fast.
    3. Top right: type code. For nouns, > points to the ending model.
    4. Bottom left: copyable sentence.
    5. Bottom right: grammar cue that explains the sentence.

    Compact codes

    N noun / base case V verb P preposition adj adjective m.an masculine animate noun m.in masculine inanimate noun f feminine grammatical gender n neuter grammatical gender >model declines like that noun G genitive D dative A accusative L locative I instrumental P+G preposition asks genitive inf infinitive verb + used with ipf→pf doing → done / paired choice

    Cases are operations

    N G D A L I

    A cue such as do+G: města says which case the sentence needs and gives the real form to copy. The dictionary uses six working cases; vocative is for calling someone and is not part of the row system.

    CodeCaseUse in the dictionaryExample cue
    Nnominativebase naming formměsto = town
    Ggenitivefrom, to, without, quantitydo+G: města
    Ddativeto/for someone, target of help or understandingpomůžu + D
    Aaccusativedirect object or motion targetChci vodu.
    Llocativefixed place after v, na, ov+L: městě
    Iinstrumentalwith, by, using, transport/methodI: kartou

    Exception marks

    when no model applies
    MarkMeaningWhat to do
    N plplural-only or mostly plural nouncopy the row form first: dveře, peníze, kalhoty.
    N indecl.does not visibly decline in normal usekeep the same form: menu, wifi, taxi.
    irregulardoes not follow the ordinary table cleanlytrust the cue form before trying to generalize.
    N m.in / N m.angender known, model not yet assignedtreat as a data-quality warning to refine later.
    adjadjectivedictionary often stores the masculine base; it must agree with the noun later.
    phrase / sentencefixed usable Czechcopy as a whole before breaking it apart.
